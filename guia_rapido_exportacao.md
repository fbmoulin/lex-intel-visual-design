## Como Exportar uma Petição

### 1️⃣ Preencha o Editor
- Acesse a página **Editor**
- Preencha todos os campos da petição
- Verifique o preview em tempo real

### 2️⃣ Clique em "Exportar"
- Botão localizado no canto superior direito
- Ícone de download (FileDown)

### 3️⃣ Configure a Exportação

#### **Formato**
- **PDF:** Para protocolo oficial (não editável)
- **DOCX:** Para edição posterior (Microsoft Word)

#### **Cabeçalho** (opcional)
- ✓ Ativar cabeçalho
- Logo: `https://seuescritorio.com/logo.png`
- Texto: `Nome do Escritório - OAB/UF 12345`

#### **Rodapé** (opcional)
- ✓ Ativar rodapé
- Texto: `Endereço, telefone, e-mail`
- ✓ Incluir numeração de páginas

### 4️⃣ Visualize o Preview
- Clique na aba **Preview**
- Verifique como ficará o documento final
- Volte para **Configurações** se precisar ajustar

### 5️⃣ Confirme a Exportação
- Clique em **Exportar PDF** ou **Exportar DOCX**
- Aguarde o processamento
- Arquivo será baixado automaticamente

## Quando Usar Cada Formato

### 📄 PDF
✅ Protocolo em tribunais  
✅ Envio para clientes  
✅ Arquivo permanente  
✅ Preservar elementos visuais (gráficos, timelines)

### 📝 DOCX
✅ Revisão colaborativa  
✅ Edição posterior  
✅ Modelos reutilizáveis  
✅ Cliente solicita formato editável

---

## Dicas Profissionais

### Logo do Escritório
- Use imagens em alta resolução (PNG ou JPG)
- Tamanho recomendado: 200x60 pixels
- Fundo transparente (PNG) para melhor resultado

### Texto do Cabeçalho
- Mantenha conciso e profissional
- Inclua OAB/UF para credibilidade
- Exemplo: `Silva & Associados - OAB/SP 123456`

### Texto do Rodapé
- Inclua informações de contato essenciais
- Use quebras de linha para organizar
- Exemplo:
  ```
  Rua das Flores, 123 - Centro - São Paulo/SP
  Tel: (11) 1234-5678 | contato@escritorio.com.br
  ```

### Preview
- **Sempre** visualize antes de exportar
- Verifique se todas as informações estão corretas
- Confirme que cabeçalho e rodapé estão como desejado

## Solução de Problemas

### ❌ "Preview não encontrado"
**Solução:** Ative o preview antes de exportar (botão "Mostrar Preview")

### ❌ "Erro ao exportar documento"
**Solução:** 
1. Verifique sua conexão com a internet
2. Tente novamente em alguns segundos
3. Se persistir, recarregue a página

### ⚠️ Logo não aparece no documento
**Solução:**
1. Verifique se a URL está correta
2. Certifique-se de que a imagem é acessível publicamente
3. Teste a URL em uma nova aba do navegador

## Qualidade dos Documentos

### PDF
- **Resolução:** 2x (alta qualidade)
- **Formato:** A4 (210mm x 297mm)
- **Paginação:** Automática
- **Elementos Visuais:** Totalmente preservados

### DOCX
- **Margens:** 1 polegada (padrão ABNT)
- **Formatação:** Profissional automática
- **Compatibilidade:** Microsoft Word, LibreOffice, Google Docs
- **Editável:** Sim, totalmente
